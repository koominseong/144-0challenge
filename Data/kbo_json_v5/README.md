# KBO 팀·연도별 선수 JSON (1982–2025) — v5

## 로스터 슬롯
SP×3, RP×3, C, 1B, 2B, 3B, SS, LF, CF, RF, DH

## position 변환 규칙
- SS  → ["SS","2B"]
- CF  → ["CF","RF","LF"]
- RF/LF → ["RF","LF"]
- IF  → ["2B","3B","SS","1B"]
- C/1B/2B/3B/DH → 그대로
- P → 경기당 이닝(IP/G)으로 판별:
    · 4.5 이상 → ["SP"]
    · 3.0~4.5 → ["SP","RP"] (스윙맨)
    · 3.0 미만 → ["RP"]
    · 세이브+홀드 10 이상이면 RP 적격 보장
- OF → 원본 데이터에 LF/CF/RF 구분이 없어 스피드 기준 추정:
    · 도루 10개 이상 또는 도루/PA 3% 이상 → ["CF","RF","LF"]
    · 그 외 → ["RF","LF"]
    · 도루 데이터 없는 구간(조~힐)은 HR 8개 미만이면 CF 포함, 이상이면 코너만
