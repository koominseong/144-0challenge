# KBO PLAYER LIFE

한 명의 한국 프로야구 선수를 18세부터 은퇴까지 직접 키우는 장기 커리어 모드 프로토타입.

## 플레이 흐름

매 나이를 건너뛰지 않고 다음 순서로 진행한다.

1. 훈련
2. 생활·가족
3. 에이전트 / 감독 / 단장
4. 시즌 진행
5. 시즌 결과
6. 다음 나이

18세부터 40세 시즌까지 진행되므로 기본적으로 23시즌 × 여러 상호작용으로 70개 이상의 선택/행동이 발생한다.

## 포함된 시스템

- KBO 신인드래프트
- 고졸 / 대졸 출신에 따른 FA 자격 진행
- 145일 등록 시즌 기반 FA 서비스 카운트
- FA 잔류 / 타 구단 이적
- 보상선수 시스템은 플레이어가 직접 결정하지 않으므로 제외
- 포스팅 / 해외진출
- MLB 도전 및 KBO 복귀 흐름
- 아시안게임 / 올림픽 등 국제대회와 병역 혜택 이벤트
- 상무 / 현역 선택
- 에이전트 5종 성향
- 연봉 및 시장가치 협상
- 단장/감독이 제안하는 트레이드
- 가족 / 결혼 / 자녀
- 등번호 화면
- 훈련실
- 부상/컨디션의 간접 반영
- 시즌별 OVR 성장/노쇠화
- 시즌 성적 / 통산 기록 / MVP / 골든글러브 / 우승

## 실제 규정 반영 메모

현재 게임은 2022 시즌 종료 후 적용된 FA 취득 기간 단축(고졸 8년, 대졸 7년)과 145일 등록 기준을 기본 로직으로 사용한다. KBO의 2026년 FA 공시 자료와 규정 변경 자료를 기준으로 추후 세부 계약/등급 규칙을 더 정밀하게 확장할 수 있다.

아시안게임/올림픽 병역 혜택은 실제 병역법·대회별 대상 여부를 구현 시점의 최신 규정으로 최종 검증해 세부 조건을 고정해야 한다.
